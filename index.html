SVG 整形ツール

Office などで出力した SVG を、読みやすく整形し、ブログなどで使いやすい大きさに調整します。ファイルはこのブラウザーの中だけで処理され、どこにも送信されません。

SVG をここにドロップ またはクリックしてファイルを選択
SVG のコードを Ctrl+V で貼り付けることもできます
表示
見た目の大きさ
px
高さは縦横比を保って自動で計算します
width と height を外し、viewBox だけを残します
余白
周りに px の余白を残す
フォント
Mac では Windows と同じ游ゴシックで、游ゴシックがない端末（iPhone、Android など）では近いゴシック体で表示されるようにします。文字の位置は固定されているため、游ゴシック以外で表示されると、文字の幅が変わって少しずれることがあります
